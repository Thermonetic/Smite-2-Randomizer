# Smite-2-Randomizer
A simple application allowing you to generate random builds and gods for the Smite 2 video game.
Deployed at https://thermonetic.github.io/Smite-2-Randomizer/

Unofficial fan project. Not affiliated with or endorsed by Hi-Rez Studios or Titan Forge Games. SMITE 2 and related artwork and trademarks belong to their respective owners.

node scripts/generate-offline-assets.mjs needs to be run in the powershell at the root folder of the project if any files are changed. Not necessary if ran with a live server.
